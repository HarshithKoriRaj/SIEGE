# Siege Command Center

Next.js App Router frontend for the Siege MVP.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and run the backend on `http://127.0.0.1:8000`.

## Configuration

- `NEXT_PUBLIC_API_BASE_URL`: FastAPI backend URL. Defaults to `http://127.0.0.1:8000`.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```
